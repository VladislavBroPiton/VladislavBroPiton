### 🚀 Мои проекты

| Проект | Стек | Что делает |
|:-------|:-----|:------------|
| **DocuHelper Mini App** | `aiogram 3` `aiohttp` `pgvector` `Cohere` `tsvector` | AI‑консультант по трейдингу. Чат в Telegram Mini App. Гибридный поиск (векторный + текстовый). Кэширование эмбеддингов и ответов, rate limiting, статистика. → [GitHub](https://github.com/VladislavBroPiton/DocuHelperMiniApp) |
| **BeautyBook Bot** | `aiogram 3` `Google Calendar API` `asyncpg` `Flatpickr` | Запись в салон красоты через Telegram Mini App. Защита от овербукинга, автоматические напоминания, интеграция с Google Календарём. → [GitHub](https://github.com/VladislavBroPiton/BeautyBook) |
| **Quiz-Funnel Bot** | `aiogram 3` `Google Sheets API` `aiohttp` | Интерактивный квиз в Telegram. Собирает ответы в Google Sheets, тёмная/светлая тема, анимации. Идеально для лидогенерации. → [GitHub](https://github.com/VladislavBroPiton/Quiz-Funnel) |
| **DocuHelper Forex** | `aiogram 3` `pgvector` `OpenRouter API` `Cohere` | AI‑помощник трейдера с RAG. Отвечает на вопросы по загруженным текстовым файлам. Полнотекстовый поиск + эмбеддинги. → [GitHub](https://github.com/VladislavBroPiton/DocuHelperForex) |
| **Telegram Clicker Bot** | `aiogram 3` `Three.js` `PostgreSQL` `Mini App` | 3D‑кликер с 13 боссами, системой крафта и прокачки. Игровая экономика, таблицы лидеров, Mini App с трёхмерной графикой. → [GitHub](https://github.com/VladislavBroPiton/telegram-clicker-bot) |

> Другие проекты (Shop Bot, Lead Converter, Booking Bot) — в плане. Могу реализовать под ваш запрос.

### 🔥 Что я умею на практике

| Для бизнеса | Технически |
|:------------|:------------|
| 🤖 **Чат‑боты под ключ** – поддержка, консультации, продажи, запись. | Асинхронные боты на aiogram 3, вебхуки, FSM, middleware, логирование. |
| 📱 **Telegram Mini Apps** – интерфейсы прямо в Telegram. | HTML/CSS/JS, адаптив, кастомные анимации, Telegram WebApp API, валидация initData. |
| 📅 **Интеграция с Google** – Календарь, Таблицы, Docs. | OAuth 2.0, async Google API client, автоуведомления, синхронизация в реальном времени. |
| 🧠 **AI и базы знаний** – боты, которые отвечают по вашим документам. | RAG, pgvector (поиск по эмбеддингам), tsvector (полнотекстовый), гибридный поиск, Cohere/OpenRouter. |
| 📊 **Сбор и аналитика** – квизы, опросы, воронки, сохранение в таблицы. | Google Sheets API, обработка форм, построение отчётов. |
| 🚀 **Деплой и CI/CD** – чтобы бот работал 24/7 и обновлялся без вас. | Render, GitHub Actions (автоиндексация), cron-job.org для пинга, Docker (готовлю). |
| 🔒 **Enterprise‑фичи** – безопасность, контроль нагрузки. | Rate limiting, кэширование (TTL), пулы соединений, защита от дублей. |
